# Vamos controlar Microservo!
Circuito feito no Tinkercad, onde há um controle de Microservo com Potenciômetro onde, quando giramos o potenciômetro, o microservo se move junto.

O Arduino lê o estado do botão pelo pino 7
Controla o LED pelo pino 10
Materiais necessários
Qtd	Componente
1	Placa Arduino UNO
1	Cabo USB
1	Protoboard
1	Microservo posicional
1	Botão tipo push button
10	Fios de jumper macho-macho
